# Kode etik

Repo ini terbuka untuk siapa saja yang mau bantu bikin game ini lebih seru.

- Kritik ide dan kode, bukan orangnya.
- Tidak ada pelecehan, serangan pribadi, ujaran kebencian, atau konten SARA, baik di issue, PR, maupun diskusi.
- Satire di game ini menyasar fenomena. Jangan pakai repo ini untuk menyerang, memfitnah, atau membocorkan data pribadi siapa pun.

Maintainer berhak menghapus komentar, menutup PR atau issue, dan memblokir akun yang melanggar.
Lapor pelanggaran ke maintainer lewat issue.
